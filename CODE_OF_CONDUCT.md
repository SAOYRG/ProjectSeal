# Code of conduct

Treat contributors with respect. Welcome different backgrounds, focus criticism
on code and ideas, and respect people's privacy. Harassment, threats,
discrimination, doxxing and sexualized conduct are unacceptable.

Maintainers may remove abusive content, warn participants, or restrict access
proportionately. Decisions should be fair and allow affected people to be heard.
For conduct concerns, contact repository maintainer
[SAOYRG](https://github.com/SAOYRG) by opening an issue requesting a private channel
without posting sensitive details. Continue the report privately once the
maintainer provides that channel.
These expectations apply to repository discussions and official project spaces.
